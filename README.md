CORE CONCEPT

LIMN Studio is a connected professional creative-software ecosystem designed for people creating human-produced media.

It provides professional creation tools for:

- images and illustration

- film and video

- animation

- audio and music

- 3D creation

- publishing

The defining difference is that LIMN does not merely inspect a finished file afterward and guess whether AI created it.

LIMN records the production history while work is being created inside the LIMN environment.

The core idea is:

Professional creative software + verifiable human production history.

LIMN can record meaningful creation information such as:

Creator → Tool → Action → Asset → Revision → Approval → Final Work

The goal is to provide a credible production history showing how a piece of media was created.

Do NOT describe LIMN as an AI detector.

The important distinction is:

Traditional AI detection asks:

“Does this finished file look AI-generated?”

LIMN asks:

“Where is the creation history that produced this work?”

LIMN verifies the production process by recording creation inside its own software ecosystem.

Do NOT make claims such as:

- “LIMN proves no AI ever influenced an idea”

- “LIMN can determine what a creator looked at”

- “LIMN tracks everything on a computer”

Those are NOT part of the website.

CONNECTED ECOSYSTEM

All five applications operate through one connected LIMN environment.

A creator should have one LIMN account and be able to move project material between compatible LIMN applications without breaking the project history.

Example workflow:

ImageLine

Character artwork created

↓

ModelWorks

Character modeled and rigged

↓

FilmWorks

Character animated in a film

↓

SoundWorks

Dialogue, music and sound created

↓

FilmWorks

Final sequence assembled

LIMN should preserve the relationship between those pieces of work throughout the workflow.

LIMN-NATIVE PROJECT FORMAT

LIMN has a native project format:

.limn

A .limn project is the full LIMN creation package.

It may contain:

- project media

- layers

- timelines

- keyframes

- 3D assets

- audio tracks

- fonts and resources

- revision history

- contributor identities

- timestamps

- application/action history

- creation events

- cryptographic verification information

- verification status

- links between LIMN applications

Example:

MilesAway.limn

Do NOT make this a major homepage headline.

This belongs on Learn / Technology / Verification information pages.
